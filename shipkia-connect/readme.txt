Connect your WooCommerce store to Shipkia to automatically sync shipment tracking info and provide tracking updates to your customers.

== Description ==

Shipkia Connect allows you to seamlessly integrate your online store with the Shipkia platform. 

Key features include:
* Automatic shipment tracking synchronization.
* Display tracking information on the customer's "My Account" page.
* Easy configuration and setup.
* Enhanced customer experience with real-time tracking updates.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/shipkia-connect` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Go to WooCommerce > Shipkia Connect to configure the plugin and connect to your Shipkia account.

== Frequently Asked Questions ==

= Do I need a Shipkia account? =

Yes, you need an active Shipkia account to use this plugin.
